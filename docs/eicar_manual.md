# Отдельная ручная проверка EICAR

Обычная сборка, тесты и генератор не скачивают и не создают EICAR. Поставляемые сигнатуры относятся только к собственным фикстурам. Официальный [EICAR Anti-Malware Testfile](https://www.eicar.org/download-anti-malware-testfile/) предназначен для проверки реакции антивирусов; файл не является реальным вредоносным образцом. Наш сканер не запускает файлы и не распаковывает архивы.

1. Самостоятельно откройте официальную страницу и ознакомьтесь с её инструкцией. Если правила вашей среды разрешают этот тест, вручную получите **неархивный** тестовый файл в отдельный каталог. Не запускайте его. Если установленная защита блокирует загрузку/доступ, остановите сценарий и запишите «перехвачен защитой ОС; сканирование Решето не выполнено». Не отключайте защиту, не добавляйте исключения и не пытайтесь обойти блокировку.
2. Подготовьте отдельный JSON ниже. SHA-256 стандартного 68-байтового варианта приведён в [RFC 7203, раздел 5.1](https://www.rfc-editor.org/rfc/rfc7203.html#section-5.1). Не заменяйте ожидаемый digest результатом хеширования произвольного проверяемого файла. Размер/переводы строк влияют на точный HASH; изменённая копия не обязана совпадать. Официальная страница также описывает варианты пробельных окончаний; данная HASH-сигнатура относится только к точному исходному файлу.

   ```json
   {
     "version": "test-eicar-1",
     "signatures": [{
       "id": "test-eicar-sha256", "name": "ТЕСТ: официальный файл EICAR",
       "kind": "HASH", "algorithm": "SHA-256", "version": "1", "enabled": 1,
       "value": "275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f"
     }]
   }
   ```
3. Сохраните описание в `eicar-signature.json` и создайте только базу, без фикстур:

   ```powershell
   ./build/windows/Release/resheto-prepare.exe --source eicar-signature.json --output eicar-db --database-only
   ./build/windows/Release/resheto-cli.exe --path eicar-manual/eicar.com.txt --db eicar-db/signatures.db --storage eicar-db/resheto.db --json
   ```

4. Если файл доступен и соответствует эталонному digest, ожидается `signature_match`, основание SHA-256 и код 1. Исчезновение/отказ доступа — `not_checked`/код 2, а не успешный тест обнаружения. Сохраните вывод и версию базы. После перезапуска `--last --storage eicar-db/resheto.db --json` должен показать то же задание.

Для Ubuntu используйте `build/release/resheto-prepare` и `build/release/resheto-cli`. Этот сценарий в текущей работе **не выполнялся**, EICAR не загружался. Для проверки основных возможностей достаточно безопасного набора `data/demo_signatures.json`.
